# Tushar Jaiswal — 3D Portfolio

Personal portfolio for Tushar Jaiswal featuring Python, machine learning and data analytics projects.

## Live deployment
This repository is designed for GitHub Pages. Publish from the `main` branch and repository root in **Settings → Pages**.

## Features
- Animated Three.js 3D background
- Dark/light mode with saved preference
- Scroll reveal animations and 3D project-card tilt
- Responsive mobile layout
- GitHub project links
- Contact section

## Local development
Open `index.html` or run `python -m http.server 8000` and visit localhost on port 8000.
